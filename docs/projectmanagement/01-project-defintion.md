# Project Definition

## Project Title
Implementation of a Learning Dashboard

## Project Duration
The project is planned from September 9, 2026, to October 1, 2026.

## Project Goal
The goal of this project is to develop a Learning Dashboard that
provides a structured overview of the user's learning progress.

The application should allow users to manage learning subjects,
learning goals, programming languages and frameworks. The learning
progress should be presented through suitable visualizations and
editable elements.

### Personal Goal
In addition to developing the application, the project has several
personal objectives:

- Gain practical experience in full-stack web development.
- Improve my knowledge of Next.js and related technologies.
- Build a project that can be presented in my GitHub portfolio.
- Apply and consolidate knowledge gained through previous learning
  and certificates.

## Project Management
The project is developed as an individual project without a team.
Due to the limited project duration, a lightweight and iterative
project management approach is used.

The project starts with the definition of the main requirements and
the desired scope of the application. These requirements are used to
define a Minimum Viable Product (MVP) that represents the target for
the project. 

The implementation is divided into smaller features and milestones.
Requirements may be refined during implementation when technical
constraints or new insights arise.

To keep the project within the planned timeframe, features are
prioritized and the available time is used as a constraint.
Additional features may be postponed or omitted if they are not
essential for the MVP.

At the end of the project, the implemented and tested version is evaluated
against the initial requirements and project goals.
